
# DSK-Shop

> Une expérience e-commerce moderne, simple et responsive.

![DSK-Shop Preview](./screenshots/home.png)

##  Aperçu

DSK-Shop est une plateforme e-commerce conçue avec **React + TypeScript**, avec une interface moderne orientée produit et une expérience fluide sur mobile et desktop.

###  Fonctionnalités

-  Catalogue de produits
-  Recherche et filtrage
-  Pages produits
- Panier
- Processus de commande
- Design responsive
-  Interface rapide et moderne

## Technologies

- **React**
- **TypeScript**
- **Vite**
- **Tailwind CSS**
- **Git & GitHub**
